# NPV Calculator Solution

## Overview

This solution provides a robust, production-ready **Net Present Value (NPV) Calculator** web application built with modern .NET 8 technologies.  
It features a clean Blazor UI frontend, a secure and validated Minimal API backend, comprehensive unit and integration tests, and strong model validation using FluentValidation.

---

## Features

- **Blazor WebAssembly UI:**  
  Interactive single-page app for entering cash flows and discount rate ranges, viewing tables and charts, and getting instant feedback.
- **.NET 8 Minimal API Backend:**  
  Fast, scalable, and validated endpoints for NPV calculations.
- **Model Validation:**  
  All inputs validated via FluentValidation for business and security rules.
- **Shared Contracts:**  
  DTOs/Models are shared between client and server for DRY and type safety.
- **Testing:**  
  Comprehensive unit and integration tests ensure reliability.
- **Modern Dev Practices:**  
  Follows best practices for folder structure, dependency injection, async code, and separation of concerns.
